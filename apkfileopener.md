Privacy Policy for APK File Opener

Effective date: September 26, 2026

Coobbi built APK File Opener. This Privacy Policy explains how the app handles information when you use it.

Local File Processing

APK File Opener allows you to select APK files and supported archive containers from your device for local inspection.

The app processes only files that you explicitly select.

Selected files and their contents are processed locally on your device. APK File Opener does not upload selected APK files, archive files, or their contents to Coobbi servers.

Depending on the file type and available information, APK File Opener may locally inspect or display information such as:

APK package information
AndroidManifest information
Application metadata
Requested and declared permissions
Activities
Services
Broadcast receivers
Content providers
Intent filters
DEX file information
Native library information
APK signing and certificate metadata
Certificate fingerprints
File hashes
Archive file entries
Search results generated from locally analyzed file information

This information is processed locally by the app and is not uploaded to Coobbi servers.

Search queries entered in APK File Opener are processed locally and are not sent to Coobbi servers.

Recent Files

To provide recent-file functionality, APK File Opener stores limited metadata about files you previously opened.

This may include:

File display name
Content URI
File type
File size
Time the file was opened

Recent-file information is stored locally on your device.

You can remove recent-file entries from the app or clear the app's data through Android system settings.

Recent-file information is excluded from Android cloud backup and device-to-device transfer where supported by the operating system.

Temporary Files and Cache

APK File Opener may create a temporary local copy of a selected file in the app's private cache directory so that the file can be inspected.

These temporary files remain on your device.

APK File Opener does not upload cached files to Coobbi servers.

The app periodically removes old temporary analysis files, and Android may also remove cached data when storage space is required. You may also clear the app's cache or data through Android system settings.

File Export and Sharing

APK File Opener allows you to export or share certain information or files when you explicitly choose to do so.

Examples may include:

Archive entries
Extracted files
Analysis reports
File hashes
Certificate fingerprints

When you use Android's system share or export features, the information is sent only to the location, application, or service that you select.

Coobbi does not automatically receive this information.

Advertising

APK File Opener uses Google Mobile Ads to display advertisements.

Google Mobile Ads may process information such as:

IP address
Device and advertising identifiers
App interactions
Advertising interactions
Diagnostic and performance information
Other information required for advertising, analytics, and fraud prevention

This information is handled by Google according to Google's privacy policies and the configuration of Google Mobile Ads.

Coobbi does not sell or share the contents of APK files or archive files that you select with advertisers.

Privacy Choices and Consent

APK File Opener uses Google's User Messaging Platform (UMP) to manage privacy and advertising consent choices where required.

Depending on your region and applicable privacy requirements, the app may display a consent message before requesting advertisements.

Where required, APK File Opener also provides a Privacy Options entry in Settings so that you can review or change available privacy choices.

Advertising requests are not made until the app determines that ads may be requested under the applicable consent state.

Third-Party Services

APK File Opener uses third-party services provided by Google for advertising and privacy consent management.

These services may process information independently according to their own privacy policies.

The app currently uses:

Google Mobile Ads
Google User Messaging Platform

APK File Opener does not use these services to upload or analyze the APK or archive files that you select.

Data Retention and Deletion

APK File Opener does not maintain a Coobbi server-side database containing your selected APK files, archive files, Manifest information, components, certificates, hashes, or search queries.

Recent-file metadata remains locally on your device until you remove it or clear the app's data.

Temporary analysis files are stored in the app cache and may be automatically deleted by the app or Android.

You can remove locally stored application data at any time through Android system settings.

User Accounts

APK File Opener does not require you to create an account.

The app does not maintain user profiles or a Coobbi account database for APK File Opener.

Security

APK File Opener performs file inspection locally on your device.

The app is a file inspection tool and does not determine whether an APK is safe, malware-free, trustworthy, or from an official publisher.

Signing and certificate information displayed by the app is technical metadata and should not be interpreted as verification of publisher identity or application safety.

You should open files only from sources you trust.

No method of electronic storage or transmission can be guaranteed to be completely secure.

Children's Privacy

APK File Opener is not directed at children.

Coobbi does not knowingly collect personal information from children through APK File Opener.

Changes to This Privacy Policy

We may update this Privacy Policy when APK File Opener's features, third-party services, or data practices change.

The current version of this Privacy Policy will be published at the privacy-policy address shown in the app and in Google Play.
